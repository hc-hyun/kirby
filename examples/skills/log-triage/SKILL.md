# Log triage

1. Establish the available time window and device/build information.
2. Group related events by component and timestamp.
3. Separate observed errors from plausible causes.
4. Attach supplied evidence identifiers to observations and hypotheses.
5. Recommend read-only checks for missing evidence. Do not run shell commands.

Do not claim that temporal correlation proves causation.
