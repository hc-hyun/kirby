# 예제 역할

VOC·로그 분석을 위한 합성 입력, 역할 설정, 스킬과 결과 스키마입니다.
실제 고객 데이터나 조직이 승인한 분류 기준이 아닙니다.

- `catalogs.example.yaml`: 역할·스킬·스키마 참조
- `roles/`: 역할별 실행 제한과 공개 기능
- `skills/`: 필수 역할 지침과 선택 절차
- `schemas/`: 역할 설정 및 출력 계약
- `inputs/`, `results/`: 합성 입력과 유효한 결과 예시

현재 운영 경로는 번들 스킬을 읽는 도구만 연결합니다. 카탈로그의 외부 MCP 참조는
향후 실제 서버 설정을 연결할 위치이며, 선언만으로 외부 도구를 사용할 수는 없습니다.
